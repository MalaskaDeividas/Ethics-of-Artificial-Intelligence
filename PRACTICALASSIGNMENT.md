### **Submission format**

The submission format is threefold with the following components to be submitted here on Canvas:

* an **8-12**  **minute demo video ** (no less, no more),
* a **1-2 page written description** of the code/data source and the results  **with references to all used sources ** (including referencing AI code writing tools),
* and the **code submitted as a zip-file** (or as a link to a GitHub repository)

The video is the main examination component and should contain the following components:

* Motivation and application area of the system (ca 1-3 min).
* Visual demo of the system/data analysis and "what it does" (ca 2-3 min).
* Coding/technology choices and detailed explanations of the implementation and the functionality of the different parts of the code (ca 3-4 min).
* Discussion on the system's success concerning the intended application area and the ethical implications of the system (1-3).

You can record the video as a Zoom call with a PowerPoint presentation or as a "real-world demo" with a cellphone camera, or in some other format that captures all the required components. All members of the group should be participating in the video in some form or other.

**NOTE:** All videos will be shared with the whole class, so make sure that it is something you are proud to showcase.

### Option 1: Implement an Autonomous Agent or Creative System

Inspired by the seminar on computational creativity, you are encouraged to play around with the idea of building an autonomous system. You can consider building an autonomous agent that, like an NPC, navigates space with some purpose or has conversations with a user, or go into a more creative direction by building a system that generates something like music, pictures or poetry - your imagination sets the limit!

You can use any technology/programming language, but it is important to remember that the idea is that the system is "autonomous and/or creative in its own right" ( *the idea is to approach an autonomous system with self-expression* ). This means that it should be able to act in some way on its own (after "being started"), and the results of its actions should be visible to a human interactor. You need to have some form of input/training data, some form of transition of that input/data, and an output.

Note that it is not enough to use the APIs of generative AI algorithms. You have to design the project/system yourself in some format.

**Warning:** Do not try to do something with Deep Learning/neural networks. It is likely too complex and requires a bit too much machine power for it to be a good project of this size.

**Tip: ***For the data:* Think of something with simple data points like 2d grid maps (as in old computer games), MIDI files, colour pixels, text strings/lists, and numbers. *For the transformation rules:* Play with ideas such as coding rules/random functions, using cellular automata or evolutionary algorithms, mathematical functions, etc.
